# Touchline Manager

A mobile football manager game by **Forge Frame** (com.forgeframe.touchline). Built the Dawn of Dynasties way: plain HTML + JS, every number in `js/data.js`, Capacitor for Android.

- `npm run www` packs the app folder; `npm run android` syncs it into the Capacitor project.
- APKs are built by GitHub Actions only on commits containing `[release]`.
- `node tools/balance.mjs 30` runs 30 headless seasons and prints pace numbers.
- Clubs, players and names are fictional.
